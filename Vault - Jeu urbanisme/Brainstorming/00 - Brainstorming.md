# 💭 Brainstorming

> Le dépôt des discussions brutes avec Claude. **Rien ici n'est décidé.** Tant qu'une idée n'est pas remontée dans [[Décisions arrêtées]] ou dans une note de [[00 - Index|système]], elle n'engage à rien.

Je dépose les `.md` de conversation dans ce dossier tel quel, sans les nettoyer. Le tri se fait après, pas pendant.

---

## 📥 Comment déposer une discussion

1. Coller le `.md` dans `Brainstorming/`
2. Le renommer : `AAAA-MM-JJ — sujet en 3 mots.md`
3. Ajouter l'en-tête du [[_Modèle discussion]] en haut (30 secondes, c'est ce qui rend le fichier retrouvable dans 6 mois)
4. Le lister dans [Les discussions](#-les-discussions) ci-dessous

Si l'étape 3 ou 4 saute, ce n'est pas grave — mieux vaut un fichier brut déposé qu'une discussion perdue.

## 🔁 Comment ça ressort

Une discussion de brainstorming a rempli son rôle quand quelque chose en sort ailleurs :

- une décision tranchée → [[Décisions arrêtées]]
- une question qui reste ouverte → [[Questions ouvertes]]
- un apprentissage → [[Journal]]
- un système modifié → la note concernée, avec un lien retour vers la discussion

Une fois la discussion vidée de sa substance, passer son `statut` à `digéré`. Elle reste sur place comme archive : on ne supprime pas, on marque.

**Statuts** : `brut` (déposé, jamais relu) · `en cours` (relu, tri commencé) · `digéré` (tout ce qui valait est remonté ailleurs) · `abandonné` (piste morte, gardée pour ne pas la refaire)
