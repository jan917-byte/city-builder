# 🏙️ Desire Path — city-builder de transformation urbaine

> Un city-builder PC où le joueur ne construit pas : il **décide**. Une ville ordinaire, voiture-dépendante, qu'on transforme sur vingt ans. Objectif : **inspirer**, pas simuler la bureaucratie.

**Le prototype** : [[Wehrau]], une petite ville entière (~5 350 hab.), frappée par une crue au premier jour. Le joueur reloge, rouvre un pont, relève le faubourg, puis prépare la ville à la crue suivante → [[Boucle de jeu]]
**Ce qu'il teste** : *après la première réparation livrée, le joueur veut-il choisir la suite ?*
**Où on en est** : `ETAT.md` et `Prototype/00 - Prototype.md`, à la racine du dépôt — le vault ne tient pas l'état, il tient le design.
**La règle du vault** : le jeu a raison sur le vault. Une note que la maquette contredit se corrige (109).
